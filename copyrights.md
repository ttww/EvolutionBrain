# Third-Party Copyright Permissions

This project bundles a small amount of third-party material for which explicit permission to use
it in this open-source project (and the related 2011 master thesis) was obtained by email. The
original email correspondence is kept privately by the project owner and is not included in this
repository; this file only records that permission exists and what it covers.

## Brain icon image (`mh_nervenzellen.jpg`, `Brain.ico`, `Brain.icns`, `Brain.png`)
- The program icon is a collage based on an original neuron image whose source was traced to
  Markus Hofmann / MEMO-MIND Brainproducts GmbH (via `unvergesslich.de`).
- Permission to use the image (in low resolution, not the original) for the master thesis and the
  resulting open-source program was granted by Markus Hofmann's office (Karin Giesche, on his
  behalf) in March 2011.

- Permission to use and redistribute the code under this project's license was granted by
