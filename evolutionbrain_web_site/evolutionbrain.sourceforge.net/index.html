 BACKGROUND:
EvolutionBrain is a simulation environment for randomly create neuronal networks and and check their fitness in a given environment.
It was created as a playground for evolution driven simulations and developed as a master thesis project.
 STATE OF WORK:
Fully functional, but only for experts at the moment. I will add more to the "startup" guide later (look at the "Starting" menu above).

Additionally, you may look at src/main/java/tw/master/MasterProofMain.java.

 DEVELOP ENVIRONMENT:
  • Java
  • Eclipse / Maven and a own Maven-Repository
  • Project was integrated in a Jenkins CI system
  • Using the subversion system
  • Using jUnit for tests
  • Start working on Checkstyle and PMD metrics for improving code quality
