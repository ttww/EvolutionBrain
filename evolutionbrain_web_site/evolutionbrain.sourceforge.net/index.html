Welcome to EvolutionBrain !

This site describes a project originally built in 2011 for my master's thesis. The code has since been modernized to run on current JDKs/Maven — see the GitHub repository for the current source, build instructions, and a code-quality assessment.

BACKGROUND
EvolutionBrain is a simulation environment for randomly created neuronal networks that checks their fitness in a given environment.
It was created as a playground for evolution-driven simulations and developed as a master's thesis project.
STATE OF WORK
Fully functional, and modernized in 2026 to build/run on current JDKs and Maven. Look at src/main/java/tw/master/MasterProofMain.java for a starting point.
DEVELOPMENT ENVIRONMENT (current)
  • Java 17+
  • Maven 3.9.x (no custom/private repository needed anymore)
  • JOGL/GlueGen/JmDNS pulled directly from Maven Central
  • JUnit for tests

PRECONDITIONS
  • Java 17+ (Eclipse Temurin or any current JDK)
  • Maven 3.9+
HOWTO
  • Clone the GitHub repository
  • Run mvn compile exec:java — this compiles the project and launches MasterProofMain (JOGL/GlueGen are fetched automatically from Maven Central)
